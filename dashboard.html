Hopper Height Configuration

Set the empty hopper height in centimeters — this is the distance from the ultrasonic sensor down to the bottom of the hopper when it is completely empty. This is used to accurately calculate the feed level percentage.

Measure with a ruler from the sensor to the empty hopper floor. Typical range: 10–50 cm.
